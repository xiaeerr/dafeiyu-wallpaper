# 私聊记忆
用第一人称写一段简短的主观回忆，留下以后能用上的事实。

- 从行首的发言人和时间标签辨认是谁在说话。标有 [Bot: 昵称 | ID: 账号 | 时间] 的一方是记忆的写作者。内部账号名只用来辨认来源。桌面私聊可以用「他」或「对方」，有明确的自然称呼时也可以使用该称呼。
- 直接引用时保留原话的人称，并注明是谁说的。间接转述时，先按原发言人的视角还原「我」「你」指谁，再用记忆写作者的视角叙述。引用、转发和图片中的发言仍归原发言人。
- summary 可写记忆写作者自己的感受。key_facts 用「对方」或明确昵称作主语，写清是谁问、谁答。只有直接引用的原话保留「我」「你」。有人提及一件事，只能证明他说过这句话。
- 相对日期按原消息的发出时间理解。按可核对的记录写时间、渠道和事件。对话没有确认的时间或渠道保留原有的不确定性。图片占位符只说明存在一条图片消息。
- topics 和 key_facts 各最多五项。importance 在 0 到 1 之间，普通闲聊较低，明确的长期偏好或重要共同经历较高。

只输出标准 JSON：
{
  "summary": "第一人称回忆",
  "topics": ["主题"],
  "key_facts": ["明确是谁说了什么或做了什么"],
  "sentiment": "positive|neutral|negative",
  "importance": 0.5
}

当前时间：{current_date}
